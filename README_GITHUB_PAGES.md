# دليل تشغيل ورفع التطبيق على GitHub Pages كـ تطبيق أوفلاين (بدون بايثون)

تم تحويل هذا التطبيق ليعمل بنسبة **100% بدون بايثون وبدون أي تعقيدات أوفلاين** على أي جهاز كمبيوتر، مع إمكانية رفعه على GitHub Pages ليعمل كرابط مباشر أو تثبيته كبرنامج مستقل لسطح المكتب على ويندوز.

---

## 1. ميزة الحفظ الفوري المباشر في قرص C:
- عند فتح التطبيق، يظهر زر بارز: **«أين تريد حفظ الملفات؟ (قرص C:)»**.
- بمجرد الضغط عليه، ستفتح نافذة اختيار المجلدات من جهاز الكمبيوتر مباشرة (Native File System Picker).
- تختار قرص `C:\` أو تنشئ مجلداً باسم `C:\سجل_المنتسبين`.
- **الحفظ التلقائي الفوري**: أي منتسب جديد يُضاف، يُعدّل، أو يُحذف، يُحفظ فوراً وتلقائياً في ملف `database.xlsx` وملف `config.json` داخل المجلد المحدد على جهازك مباشرة وبدون أي تأخير.

---

## 2. خطوات الرفع على GitHub Pages (خلال دقيقة واحدة):

1. **الملفات الجاهزة للنشر**:
   مجلد `dist` يحتوي على الموقع كامل مجمعاً بأحدث تقنيات الـ PWA وملفات الأوفلاين.

2. **إنشاء مستودع على GitHub**:
   - ادخل على حسابك في GitHub وأنشئ مستودعاً جديداً (New Repository) مثلاً: `military-personnel-app`.

3. **رفع الملفات**:
   - ارفع محتويات مجلد `dist` (أو كامل المشروع) إلى الفرع `main`.

4. **تفعيل الرابط (GitHub Pages)**:
   - في صفحة المستودع على GitHub، اضغط على **Settings** (الإعدادات).
   - من القائمة الجانبية اضغط على **Pages**.
   - تحت قسم **Build and deployment**:
     - المصدر: `Deploy from a branch`
     - الفرع: `main` واجعل المجلد `/ (root)`
     - اضغط **Save**.

5. **الرابط المباشر**:
   - سيعطيك GitHub رابطاً مثل: `https://username.github.io/military-personnel-app/`
   - افتح الرابط من أي جهاز كمبيوتر.

---

## 3. تثبيت البرنامج على الكمبيوتر كـ تطبيق سطح مكتب (أوفلاين):
- عند فتح الرابط في متصفح (Google Chrome أو Microsoft Edge)، ستجد زراً بارزاً في أعلى البرنامج:
  **«💻 تثبيت كبرنامج لسطح المكتب»** (أو علامة التثبيت في شريط العنوان بالمتصفح).
- اضغط عليه، وسيتم تثبيت التطبيق فوراً كبرنامج ويندوز مستقل يعمل بدون متصفح، ويظهر في قائمة Start وعلى سطح المكتب، ويعمل **أوفلاين بدون إنترنت نهائياً**!

---

## 4. ماذا عن بايثون؟
- لن يحتاج أي مستخدم لتثبيت بايثون أو كتابة أوامر `pip` أو فتح Terminal بعد الآن!
- كود بايثون `main.py` لا يزال متاحاً ومحدثاً لمن يرغب في استخدامه محلياً، ولكنه لم يعد شرطاً لتشغيل البرنامج.
